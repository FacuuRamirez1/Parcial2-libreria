## Qué verifica

## Comando / acción
```
docker rm -f libreria
docker run -d --name libreria \
  -p <puerto>:8000 \
  --restart unless-stopped \
  --add-host=host.docker.internal:host-gateway \
  --env-file <archivo-de-variables> \
  libreria
```
